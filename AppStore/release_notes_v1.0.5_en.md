# v1.0.5 Release Notes (App Store Submission)

```
• Added a flash effect that briefly highlights the score circle background when a goal is scored, making goals more visually noticeable.

• Timeout count indicators are now placed between team names and scores in a vertical layout (up to 3 per column).

• When 4 or more timeouts occur, columns now expand from the inside of the scoreboard toward the outside.

• The currently active timeout dot is now displayed in red, making it easy to see at a glance which timeout is in progress.

• Fixed an issue where the penalty timer continued running during timeouts on the Score Editor screen. It now stops during timeouts, matching the behavior of exported videos.
```
