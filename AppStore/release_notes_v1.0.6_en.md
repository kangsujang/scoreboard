# v1.0.6 Release Notes (App Store Submission)

```
• Added a "Video Only Merge" option when creating a new match. Skip scoreboard settings and score editing to go straight to merging and exporting your videos.

• Reduced the default scoreboard size for better video visibility. You can still pinch to enlarge as needed.

• Changed the default position of match info (tournament name, etc.) to the top-right corner, preventing overlap with the scoreboard.

• When "Video Only Merge" mode is selected, the scoreboard overlay is now hidden on the match detail screen.
```
