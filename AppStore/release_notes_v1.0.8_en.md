# v1.0.8 Release Notes (App Store Submission)

```
• Added set count tracking for sports like volleyball. Turn on "Show Set Count" in scoreboard settings to display the number of sets won [N] above each team's score.

• The score now automatically resets to 0-0 after a set is won. Only rally points within the current set are shown, keeping each set's score independent.

• Fixed an issue where exported videos from some 4K source clips were rendered at roughly half the original frame rate (around 15 FPS).

• The video management screen now shows each video's resolution and frame rate.
```
