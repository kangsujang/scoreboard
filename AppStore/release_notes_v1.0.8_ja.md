# v1.0.8 リリースノート（App Store提出用）

```
• バレーボールなどのセットカウントを編集・表示できるようになりました。スコアボード設定の「セットカウント表示」をONにすると、スコアの上に獲得セット数 [N] が小さく表示されます。

• セット獲得後にスコアが自動で0-0にリセットされるようになりました。各セット内のラリー得点だけが表示され、セット間で得点が混在しません。

• 4K動画など一部の素材でエクスポート動画のフレームレートが実際の半分（約15FPS）になってしまう問題を修正しました。

• 動画管理画面で各動画ファイルの画素数とFPS値を確認できるようになりました。
```
