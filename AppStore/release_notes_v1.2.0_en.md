# v1.2.0 Release Notes (App Store Submission)

```
• You can now choose a sport (Soccer, Basketball, Volleyball, or Rugby/Other) when creating a match. The scoreboard's display settings — set count, timeouts, penalty timers, and more — are configured automatically based on your choice

• Added a timeline on the scoring screen that shows at a glance where each recorded goal falls in the video

• The goal button's icon and label now change to match the selected sport

• Added a prominent "New Match" button on the home screen to make starting a new match easier
```
