# v1.3.0 Release Notes (App Store Submission)

```
• In the match list, scores are now color-coded for home and away teams, and the number of videos is shown at a glance

• The recording position (playback time) is now displayed more prominently, so you can see exactly where a goal will be recorded

• Tap a recorded event or a dot on the timeline to jump the video to that moment

• Added a confirmation screen before exporting that shows the details (teams, score, number of videos, and whether the scoreboard is included), so exporting now starts only after you tap the start button

• Made the "Export" button larger and placed it at the bottom of the match detail screen to make exporting easier to find

• Editing changes in scoreboard settings and video management are now protected with a confirmation prompt if you accidentally close the screen

• The confirm button is now disabled while videos are loading, with a clear loading indicator

• Added VoiceOver support so each button's purpose is read aloud
```
