# v1.3.0 リリースノート（App Store提出用）

```
• 試合一覧でスコアをホーム・アウェイで色分け表示し、動画の本数も確認できるようになりました

• 得点を記録する位置（再生時刻）を見やすく強調表示し、どの場面に記録されるかひと目でわかるようになりました

• 記録したイベントやタイムラインの点をタップすると、その場面まで動画が移動するようになりました

• エクスポート前に内容（対戦・スコア・動画本数・スコアボードの有無）を確認できる画面を追加し、開始ボタンを押してから書き出すようにしました

• 試合詳細画面の「エクスポート」ボタンを下部に大きく配置し、書き出しまでの操作をわかりやすくしました

• スコアボード設定や動画管理の編集中に誤って画面を閉じても、確認のうえ編集内容を守れるようにしました

• 動画の読み込み中は確定ボタンを押せないようにし、読み込み中であることを表示するようにしました

• VoiceOver（読み上げ）に対応し、各ボタンの内容が読み上げられるようになりました
```
