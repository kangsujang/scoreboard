# v1.3.2 Release Notes (App Store Submission)

```
• Fixed an issue where some texts were not translated in English, Korean, and Simplified Chinese

• Added confirmation prompts before deleting a segment, resetting the timer, and deleting a penalty timer, so your records are protected from accidental taps

• Fixed an issue where canceling an export was shown as a failure — you can now start again right away after canceling

• Progress display and cancellation now work correctly during the preparation phase right after starting an export

• Edits to the match info in scoreboard settings can now be reverted with "Discard Changes"
```
