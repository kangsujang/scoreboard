# v1.3.3 Release Notes (for App Store submission)

```
• Fixed an issue where the exported video's frame rate could differ from the original, causing stuttering playback. Exports now preserve the original video's frame rate

• When combining multiple videos, the export now matches the smoothest source video

• Scoreboard settings now let you hide the team names, score, and timer to show only the match info — handy when the opponent isn't decided yet or when playing practice matches against several teams
```
